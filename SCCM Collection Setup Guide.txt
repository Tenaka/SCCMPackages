Collections
    SW_C_Visual Studio Code Install
    Limit to all workstations
    Add Rule
        Query Rule
        Name - SW_C_Visual Studio Code Install
        Set Incremental Updates for collection
        Edit and paste in the following, after updating the AD Group name
 
        Collection INSTALL
            select SMS_R_SYSTEM.ResourceID,SMS_R_SYSTEM.ResourceType,SMS_R_SYSTEM.Name,SMS_R_SYSTEM.SMSUniqueIdentifier,SMS_R_SYSTEM.ResourceDomainORWorkgroup,SMS_R_SYSTEM.Client from SMS_R_System where SMS_R_System.Name in (select distinct SMS_R_System.name from SMS_R_System where SecurityGroupName = "CHANGEME\\SW_C_Visual Studio Code_Install")
 
    Update Collection Memebership
    Refresh    
        Ensure single client is present
    May need to run the AD Group Discovery\System Discovery

    SW_C_Visual Studio Code Install
    Limit to all workstations
    Add Rule
        Query Rule
        Name - SW_C_Visual Studio Code Install
        Set Schedule full update to daily
        Edit and paste in the following, after updating the AD Group name

        Collection Uninstall
            select SMS_R_SYSTEM.ResourceID,SMS_R_SYSTEM.ResourceType,SMS_R_SYSTEM.Name,SMS_R_SYSTEM.SMSUniqueIdentifier,SMS_R_SYSTEM.ResourceDomainORWorkgroup,SMS_R_SYSTEM.Client from SMS_R_System INNER JOIN SMS_G_System_AppClientState ON SMS_G_System_AppClientState.MachineName = SMS_R_System.Name WHERE  SMS_G_System_AppClientState.ComplianceState = "1" AND  SMS_G_System_AppClientState.AppName ="Visual Studio Code 1.147.0"
 
 Before Advertising for Deployment, ensure the above collections are working correctly
